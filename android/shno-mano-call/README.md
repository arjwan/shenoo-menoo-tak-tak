# شنو منو اتصال — Android

تطبيق Android مستقل للمكالمات والمراسلة الخاصة، لا يعرض الصفحة العامة لتك تك.

## المصدر والمزامنة
- API: `https://shino-mino-tak-tak.duckdns.org`
- جهات الهاتف المحفوظة على الحساب: `/api/phone-contacts`
- الأصدقاء: `/api/friends`
- التخزين المحلي: Room (`contacts`, `messages`)
- MongoDB/الخادم هو مصدر الحقيقة عند توفر الشبكة، وRoom يحتفظ بنسخة الهاتف.

## ما تم إنشاؤه
- مشروع Kotlin + Jetpack Compose مستقل.
- هوية داكنة بنفسجي/تركوازي متوافقة مع شنو منو.
- شريط تنقل للهاتف: جهاتي، الرسائل، اتصال، السجل، حسابي.
- صلاحيات جهات الاتصال والميكروفون والكاميرا.
- طبقة Room لحفظ جهات الاتصال والرسائل.
- Retrofit API client جاهز لنفس خادم الويب.

## التالي قبل APK تجريبي
1. ربط تسجيل الدخول وحفظ JWT بأمان.
2. مزامنة Room مع جهات الهاتف والأصدقاء والرسائل الفعلية.
3. ربط Socket.IO للمكالمات الواردة وحالات الاتصال.
4. WebRTC صوت/فيديو أصلي وشاشة مكالمة كاملة.
5. إشعارات المكالمات الواردة وخدمة foreground عند الحاجة.
6. اختبارات ثم `assembleDebug`.
