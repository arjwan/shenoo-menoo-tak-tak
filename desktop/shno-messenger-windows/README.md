# شنو منو ماسنجر — Windows

تطبيق Windows مستقل ذو نافذة للمحادثات وأيقونة في منطقة إشعارات Windows، يستخدم محادثات شنو منو الحالية عبر HTTPS وجلسة دخول داخل التطبيق نفسه.

## الاستخدام
- تثبيت ملف setup.exe بعد اكتمال بناء GitHub Actions
- تسجيل الدخول إلى الحساب المعتاد داخل نافذة البرنامج؛ لا تتم مشاركة كلمة المرور مع التطبيق الرئيسي ولا حفظها في ملفات محلية مخصصة
- القائمة اليمنى للمحادثات، والمحادثة المختارة في المساحة المجاورة
- الإغلاق بواسطة X يُخفي النافذة إلى System Tray؛ اختيار «خروج نهائي» ينهي البرنامج
- مكالمات الصوت والفيديو تظل مرتبطة بنفس WebRTC وخادم شنو منو

## الوضع التقني
التطبيق يستخدم Electron، ويفتح واجهة محادثات HTTPS الرسمية داخل نافذة Windows مع خصائص أصلية (tray، إدارة النوافذ، أذونات الوسائط، حماية التنقل، حزمة NSIS).
يحتاج اتصال الإنترنت وتوفّر خادم shinomino.com. **ليس تطبيقاً أوفلاين ولا يقدم FCM على Windows**؛ لا يجوز الادعاء بأن إشعارات وصول المكالمات عند إغلاق العملية أو قفل الحاسوب تعمل بدون بناء Web Push / native push مستقل واختبار حقيقي. إشعارات صفحة الويب تعتمد حالياً على بقاء البرنامج شغالاً.

## التطوير
```shell
cd desktop/shno-messenger-windows
npm install
npm test
npm start
npm run dist
```
الـ Windows installer غير موقّع برقم هوية ناشر بعد؛ قد يظهر تحذير SmartScreen إلى حين توفير شهادة Code Signing. لا تخزّن أسرار Cloudflare في هذا التطبيق.
